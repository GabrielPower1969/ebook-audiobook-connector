## 1. 一段话委托（可直接粘贴）

```
设计一个私人有声书房的 Web 应用，名叫「FlowGT 书房 / FlowGT Library」。

它是什么：一个人自己的 170 本电子书库，其中一部分配有有声书。打开一本书，正文
逐句高亮着朗读，点任意一句就从那句开始听；双击任意单词能查到音标、中文释义、
考纲标签，以及这个词在这本书里出现过的每一处原句。它同时是给英语学习者用的
精读工具：整句复读、跟读停顿、0.5 倍速。

请设计以下 9 个界面（桌面 1440、平板 iPad mini 竖持 744×1133、手机 390 三套断点）：
登录、书架、书籍详情、阅读器、练习模式面板、查词面板、设置面板、后台任务、
以及空/加载/错误三种状态。

风格要求：安静、克制、以书为主角。参考 Apple Books 的排版感与 Readwise Reader
的信息密度，但不要拟物书架木纹。主色是深绿 #00694B（暗色模式 #5BC79E），
纸面米白 #FBF9F5（暗色 #0E1411）。海报是书架的视觉主体——网格里除了封面和书名
几乎没有别的东西。

四种主题必须各出一版：跟随系统 / 日间 / 夜间 / 墨水屏。墨水屏那版是纯黑白、
零阴影、零圆角、零动画、字号更大，当前句用下划线而不是底色——这是给 Kindle 和
文石 Boox 用的，它们每次重绘都是一次全屏闪。

界面文案中英双语可切换，两种语言都要出图，中文用 PingFang SC，英文用系统字体，
正文区域用衬线体（New York / Charter / Georgia）。

不要使用任何需要下载的网络字体，不要用渐变、玻璃拟态、粒子动效。
```

## 2. 硬约束（违反即不可用）

| 约束 | 原因 |
|---|---|
| **只用系统自带字体** | 要在 Kindle 实验浏览器和 Boox 上打开，拉一个网络字体等于白屏。正文衬线：`New York`（Apple）/ `Bookerly`（Kindle）/ `Literata`（Boox/安卓）/ `Charter` / `Georgia`；界面无衬线：`PingFang SC` + 系统栈 |
| **墨水屏版零动画、零阴影、纯黑白** | 墨水屏每次重绘是一次全屏闪；灰阶阴影会拖影 |
| **正文每行 60–75 字符** | iPad mini 竖持时 19px 正文 + 34em 栏宽 ≈ 64 字符，实测最舒服。不要为了填满屏幕加宽 |
| **正文文字对比度 ≥ 4.5:1** | 亮色用 `#00694B` 而不是 `#5BEFB8`（后者白底 1.9:1，只能当装饰面，**永不用来写字**） |
| **点击目标 ≥ 44×44 pt** | 主要在手持设备上单手用 |
| **不劫持文本选择** | 长按要能调出系统词典，这是我们不内置词典的前提 |
| **中英文案等长设计** | 中文比英文短约 40%，按钮和标签要按较长的英文排版，中文不能留大片空白 |

**配色令牌**

| 令牌 | 日间 | 夜间 | 墨水屏 |
|---|---|---|---|
| `paper` 纸面 | `#FBF9F5` | `#0E1411` | `#FFFFFF` |
| `raised` 卡片 | `#FFFFFF` | `#151D19` | `#FFFFFF` |
| `ink` 正文 | `#16211C` | `#E5ECE8` | `#000000` |
| `muted` 次要 | `#78867F` | `#7F8D87` | `#444444` |
| `accent` 主色 | `#00694B` | `#5BC79E` | `#000000` |
| `now` 当前段底色 | `#EDF5F1` | `#15211C` | `#F0F0F0` |
| `now-s` **当前句**底色 | `#CFE7DC` | `#224234` | 下划线，不用底色 |
| `mark` 收藏高亮 | `#FBEBC0` | `#3E3719` | `#D6D6D6` |

## 3. 逐屏要求

### 3.1 登录 · Sign in

- 主按钮 **Google 登录**（OAuth）；次要入口：邮箱 + 密码
- 一行说明：**「不登录也能读，进度存在这台设备上；登录后进度跟着人走。」**
  这不是废话——产品真的允许匿名阅读，匿名进度在登录后会自动并入账号
- 需要出图的状态：默认、加载中、OAuth 失败、邮箱密码错误
- 中英各一版

### 3.2 书架 · Shelf ★ 视觉重心

书架是这个产品的门面，请在这一屏投入最多精力。

- **续读条**置顶：一张封面 + 书名 + 「读到 43%」+ 大按钮「接着听」
- **海报网格**：封面是主体，卡片上只有封面、书名、一行副信息（时长 · 章节数）
- **系列成组**：哈利波特七册横排一组，组标题「Harry Potter · 7 册 · 199 章 · 124 小时」，封面左上角有卷号角标
- **有声 / 无声徽章**：设计一对克制的标记。有声还要能区分 **真人朗读** 与 **AI 朗读**（两种不同图标或文字）
- 顶栏：FlowGT 标识、搜索框、语言切换 `中 / EN`、主题切换、头像菜单
- 筛选：分类（14 个）、有声/无声、语言、已读/未读
- 密度：桌面每行 6–7 张，iPad 每行 4 张，手机每行 2–3 张

### 3.3 书籍详情 · Book

- 大海报 + 书名（中英双行）+ 作者 + 分类 + 标签
- 简介（中英各一份）
- **版本选择**：同一本书可能同时有「Stephen Fry 朗读 · 8 小时 21 分」和「AI 朗读 · Kokoro」两版，让人选
- 主按钮「开始阅读」/「接着听」；次按钮「加入书单」
- 元信息：对齐率、章节数、字数、格式（epub/pdf）
- 无声书的详情页要有「**生成 AI 朗读**」的入口，点了进后台任务队列

### 3.4 阅读器 · Reader ★ 使用时长最长

三栏结构：左侧栏 / 正文 / 底部播放条。

- **左侧栏四个页签**：目录、搜索、收藏、生词。手机上收成抽屉
- **正文两级高亮**：当前**段落**淡底色 + 左侧主色竖线；当前**句子**在段内更深一层。
  这两级必须一眼分得清，又不能花——这是整个产品最关键的一个视觉判断
- **选中文字浮出气泡**：收藏 / 查词 / 朗读此处
- **底部播放条**：进度条、上一句 `‹`、后退 5 秒、播放/暂停（主色圆形）、前进 5 秒、
  下一句 `›`、重听本句 `⟲`、当前章节名、时间、语速、练习模式按钮、设置按钮。
  **手机上放不下十个控件**，请给出取舍方案（建议隐藏 ±5 秒与时间码，保留语速）
- **续读横幅**：进入时浮出「上次读到 第三章 · 17:59 [继续朗读] [从头]」，几秒后自动消失

### 3.5 练习模式面板 · Practice

给英语学习者的精读工具，从播放条的「练」按钮唤出：

- 句子高亮 开/关
- 复读：关 / 整句 / 整段
- 复读遍数：1 / 2 / 3 / 5 / 一直
- 每句后停顿：关 / 1 秒 / 2 秒 / 3 秒 / 与该句等长
- 睡眠定时：关 / 15 / 30 / 60 分 / 本章末
- 面板顶部一句话解释跟读循环：**「听一句 → 停 → 自己说一遍 → 下一句」**

### 3.6 查词面板 · Word

双击正文任意单词唤出。内容层次自上而下：

```
peculiar                              全书 4 处   [加入生词本] [✕]
/pi'kju:ljə/
a. 奇特的, 罕见的, 特殊的, 特别的; n. 特有财产, 特权
[四级] [六级] [考研] [托福] [雅思]  柯林斯★★  词频 #5505     有道 · 剑桥
───────────────────────────────────────────
THE BOY WHO LIVED
It was on the corner of the street that he noticed the first
sign of something peculiar — a cat reading a map.          ▶
───────────────────────────────────────────
（还有 3 处）
```

- 考纲标签是徽章组，请设计一套小尺寸标签
- 每条例句可点击播放，右侧有播放图标
- 手机上是底部抽屉，桌面上是右下角浮层

### 3.7 设置面板 · Settings

- 主题：跟随系统 / 日间 / 夜间 / 墨水屏（四选一，图标化）
- 字体：衬线 / Charter / Georgia / 黑体
- 字号、行距、栏宽：步进器
- 段首缩进：无 / 两字
- 跟随朗读滚动：开 / 关
- 界面语言：中文 / English
- 底部列出键盘快捷键

### 3.8 后台任务 · Jobs（管理员）

导入、抽封面、转写、对齐、TTS 都是分钟到小时级的活：

- 任务列表：类型、书名、状态、进度条、耗时
- 队列中 / 进行中 / 已完成 / 失败 四态
- 失败项可展开看日志、可重试
- 顶部一行汇总：「3 个任务进行中 · 预计还需 2 小时 14 分」

### 3.9 状态页

- **空书架**：还没有书时该显示什么
- **加载中**：书架骨架屏、阅读器骨架屏
- **错误**：书打不开、音频加载失败、离线
- **无声书**的阅读器：没有播放条时正文区怎么呈现
